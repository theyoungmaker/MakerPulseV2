# MakerPulseV2 — Glossary

- **MakerPulseV2**: a ground-up on-device UI redesign of [MakerPulse](https://github.com/theyoungmaker/MakerPulse), kept as a fully separate repository/project rather than a branch or fork-with-shared-history. Same hardware target (ST7789 240x320 "Cheap Yellow Display" / ESP32-2432S028 with XPT2046 touch) and the same backend (WiFi, LTA DataMall bus arrivals, Open-Meteo weather, KP index, PSI haze, Preferences storage, Improv Wi-Fi provisioning, the settings webpage) carried over largely unchanged — only the on-device rendering layer is being rewritten.
- **The V2.1.0 design** *(governed by `docs/MAKERPULSE_V2_SPEC.md` and its reference screens in `docs/screens/`)*: a from-the-ground-up, pixel-exact spec that supersedes all earlier ad-hoc "Colourway theme" extrapolation in this file's history. Five rules hold it together: one colourway with exactly five color roles (see **Colourway** below); no boxes (grouping from space and 1px hairlines, never borders or filled cards); accent means "look now" (reserved for the favourite bus, an arriving bus, a running timer, rain bars, stale-data warnings — never decoration); numbers first, words second (the value is the largest thing in a block, label above in small caps, context below in muted); and the same skeleton on every page (12px margins, small-caps header at y12, the same hairline heights, text tab bar at y280–320). Implementation keeps MakerPulse's existing architecture (runtime Preferences, Improv WiFi provisioning, the browser settings page) rather than the spec's own alternate suggestion of per-student `config.h` constants — the spec's UI/visual/behavioral rules are followed exactly; its provisioning model is not.
- **Colourway**: one of 6 fixed presets (Sage, Ivory, Sky, Peach, Lilac, Charcoal), each exactly five RGB565 values — `bg`, `ink`, `muted`, `rule`, `accent` — taken verbatim from the spec, no runtime derivation. The *only* color control on the settings page and the on-device Status page; there is no Accent/Text/Theme split and no custom color picker. Charcoal doubles as the night-mode palette (see **Night mode**). Supersedes "Shell colour" (MakerPulse-filament-matched 8-preset system, `docs/adr/0002-fixed-shell-colour-palette.md`) — see `docs/adr/0003-v2-spec-colourway-system.md`. Still a runtime setting on one firmware image, not a per-color firmware build — same reasoning as MakerPulse's `docs/adr/0001-screen-orientation-runtime-setting.md`.
- **Night mode**: a Status-page setting, Off or Auto. Auto renders with the Charcoal colourway and Low brightness between today's sunset and the next sunrise (19:00–07:00 if sun times are unknown), without changing the user's saved Colourway choice — it returns at sunrise.
- **Text** *(PDF term, not a screen concept — unrelated to the V2.1.0 spec's own unrelated "F_BODY" font or any Colourway role)*: in "MakerPulse Colours.pdf" (the physical-shell reference, distinct from the UI spec), the color of the silkscreened "MakerPulse" / "Designed by The Young Maker" print on the physical case (e.g. Ash Grey Matte on the Muted White case). A manufacturing detail only — it has no corresponding on-screen color role.
