# MakerPulseV2 — Glossary

- **MakerPulseV2**: a ground-up on-device UI redesign of [MakerPulse](https://github.com/theyoungmaker/MakerPulse), kept as a fully separate repository/project rather than a branch or fork-with-shared-history. Same hardware target (ST7789 240x320 "Cheap Yellow Display" / ESP32-2432S028 with XPT2046 touch) and the same backend (WiFi, LTA DataMall bus arrivals, Open-Meteo weather, KP index, PSI haze, Preferences storage, Improv Wi-Fi provisioning, the settings webpage) carried over largely unchanged — only the on-device rendering layer is being rewritten.
- **Colourway theme**: the new visual language being built page by page, named after its reference mockup ("B · Colourway theme"). Flat layout with no card borders, a light background complementary to the device's physical case color, oversized bold numerals for primary values, and plain-text tabs (active tab underlined) instead of button-style nav. Being rolled out one page at a time — Home first — rather than all at once.
- **Shell colour**: which of the 8 fixed preset colors a unit's physical 3D-printed case is (from "MakerPulse Colours.pdf": Muted White, Pastel Ice, Muted Blue, Army Blue, Muted Green, Army Red, Pastel Peach, Mandarin Orange) — the *only* color control on the settings page. Picking a Shell colour sets the on-device screen's entire palette (background, panel, divider, accent, plus a fixed hue-neutral ink/dim shared by all 8); there is no Accent/Text/Theme split, no custom color picker, and no override. This supersedes an earlier design (seed a default, stay freely customizable) — see `docs/adr/0002-fixed-shell-colour-palette.md`. A runtime setting on one firmware image, not a per-color firmware build — same reasoning as MakerPulse's `docs/adr/0001-screen-orientation-runtime-setting.md`.
- **Text** *(PDF term, not a screen concept)*: in "MakerPulse Colours.pdf", the color of the silkscreened "MakerPulse" / "Designed by The Young Maker" print on the physical case (e.g. Ash Grey Matte on the Muted White case). A manufacturing detail only — it has no corresponding on-screen color role, and isn't related to MakerPulse's old "Text color" settings-page concept (which no longer exists in V2).
